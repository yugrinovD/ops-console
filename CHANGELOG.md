# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-11-21

### Added

- Next.js BFF and UI for gogate and lmlog.
- Dashboard, playground, compare, keys/quotas, logs, requests/traces and alerts.
- SSE proxying with `Last-Event-ID` and normalized error frames.
- RBAC, CSRF protection, health cache/rate limiting and session handling.
- Sanitized documentation screenshots and Playwright coverage.
